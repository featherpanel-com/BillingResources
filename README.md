# BillingResources

Give users account-level resource pools (memory, CPU, disk, servers, databases, backups, allocations) and let them split resources across multiple servers. Requires **Billing Core** and is the foundation for **BillingResourcesNewServers** and **BillingResourcesStore**.


## Features

- **User-facing**
  - **Dashboard widget** — overview of total vs used vs available resources
  - **Server → Configuration → Resources** — allocate/deallocate resources for a specific server (within account limits)

- **Admin**
  - **Fremium Resources → Resources Management**
  - View/search all users with resource allocations
  - Set per-user resource limits
  - Default and max resource templates (global settings)
  - Statistics dashboard
  - **Admin user widget** — resource limits on user edit page
